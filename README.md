 # 🎓 Teacher's Day Message Card

A creative and interactive **Teacher's Day Greeting Card** made using **HTML, CSS, and JavaScript**. This project is designed to give teachers a simple but meaningful digital appreciation message.

## 📌 Project Overview

This website presents a personalized Teacher's Day greeting card with:

* 💌 A Teacher's Day appreciation message
* 👨‍🏫 Teacher's photo
* 🐱 Custom animated cat cursor
* ✨ Sparkle effects when clicking
* 🎁 Interactive surprise message
* 📱 Responsive webpage structure
* 🎨 Custom fonts and styling

The main HTML page contains the card layout, teacher's photo, appreciation message, signature, and interactive surprise section.

## 🛠️ Technologies Used

* **HTML5** – Creates the structure and content of the greeting card.
* **CSS3** – Controls the design, colors, layout, animations, and visual effects.
* **JavaScript** – Adds interactive features such as the custom cursor, sparkle effects, and surprise popup.
* **Google Fonts** – Uses DM Sans and Playfair Display for typography.

### 1. Teacher's Day Message

The card contains a personalized appreciation message thanking the teacher for their knowledge, patience, and guidance.

### 2. Teacher Photo

A teacher's photo is displayed inside the greeting card using an image from the `assets` folder.

### 3. Custom Cat Cursor 🐱

The project includes a custom cat-shaped cursor that follows the user's mouse movement. JavaScript updates its position based on the mouse coordinates.

### 4. Sparkle Click Effect ✨

When the user clicks anywhere on the webpage, small sparkle effects appear around the clicked location.

The JavaScript creates multiple sparkle elements and automatically removes them after a short animation.

### 5. Surprise Button 🎁

The **"Open a little surprise ✨"** button opens an additional appreciation message.

The user can close the surprise by:

* Clicking the **Close** button
* Clicking outside the surprise box
* Pressing the **Escape** key

### 6. Responsive Design

The HTML includes a viewport configuration to help the webpage display properly on different screen sizes.

## ▶️ How to Run the Project

### Step 1: Download or Clone the Project

Download all project files and keep them inside the same project folder.

### Step 2: Check the Folder Structure

Make sure your files are organized like this:

```text

├── index.html
├── style.css
├── script.js
└── assets/
    └── Randy.jpg
```

### Step 3: Open the Website

Double-click:

```text
index.html
```

or open it using a web browser such as:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

### Step 4: Interact With the Card

Try the following:

1. Move your mouse around the card.
2. Click on the webpage to create sparkle effects.
3. Click **"Open a little surprise ✨"**.
4. Read the surprise message.
5. Click **Close** or press **Escape**.

## ✏️ How to Customize

You can customize the project by editing `index.html`.

### Change the Teacher's Name

Edit the signature section:

```html
<strong>KATE CASSANDRA PUNAY</strong>
```

Replace it with your own name.

### Change the Teacher's Photo

Replace:

```text
assets/Randy.jpg
```

with your preferred image and update the image filename in the HTML.

### Change the Message

Edit the paragraphs inside the `.message` section to create your own Teacher's Day greeting.

### Change the Surprise Message

Edit the text inside:

```html
<div class="surprise-box">
```

to create your own personalized surprise message.

## 💻 JavaScript Functions

The `script.js` file controls the interactive behavior of the webpage.

It handles:

```javascript
mousemove
```

to move the custom cursor.

```javascript
click
```

to generate sparkle effects.

```javascript
surpriseBtn
```

to open the surprise message.

```javascript
closeBtn
```

to close the surprise message.

It also allows the **Escape key** to close the surprise popup.

The purpose of this project is to demonstrate how **HTML, CSS, and JavaScript** can work together to create an interactive and creative webpage.
