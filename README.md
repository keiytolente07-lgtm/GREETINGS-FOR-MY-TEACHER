# Teacher's Day Message Card

A professional, responsive greeting-card webpage built with HTML, CSS, and JavaScript.

## Files
- `index.html` — webpage structure and message
- `style.css` — design, responsive layout, animations, and cute cat cursor
- `script.js` — cursor movement, sparkle effects, and surprise modal
- `assets/Randy.jpg` — supplied photo used in the card

## Run locally
Open `index.html` in a browser.

## GitHub Pages submission
1. Create a new GitHub repository, for example `teacher-message-card`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Your published page will appear at:
   `https://YOUR-USERNAME.github.io/teacher-message-card/`

The project is already arranged so the GitHub Pages path works without changing the image link.
